## Projects

**[PokemonView](https://github.com/nkhmaladze/PokemonView)** · [pokemonview.xyz](https://pokemonview.xyz)
A price tracker for sealed Pokémon TCG products, powered by live eBay listings. A scheduled worker pulls listings every 4 hours, a two-tier matcher maps messy titles to 350+ catalog products, and a Flask API serves prices and price history to a React app. Deployed on Fly.io and Vercel with CI/CD and 200+ tests.

**[RDBMS](https://github.com/nkhmaladze/RDBMS)**
The storage and query-execution layers of a relational database in C++: a buffer manager with Clock and Random replacement policies, slotted heap pages, heap files, and relational operators including tuple, block and index nested-loop joins. I'm turning it into a self-contained database with a SQL front end.

**[Maze-solving robot](https://github.com/nkhmaladze/MazeNavigationROS)**
A TurtleBot that plans the shortest path through a maze, then drives it using laser-scan wall detection and a PD heading controller. Built with Python and ROS.
